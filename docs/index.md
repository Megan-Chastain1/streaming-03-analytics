## Custom Project

### Dataset

The dataset is sales.csv and includes information about sales including:
order ID, customer ID, item ID, quantity of item sold, and price.
I used the original dataset.
Enrichment for this dataset includes the files:
currencies.csv, discount_codes.csv, products.csv, and regions.csv.

### Data Contract

Region IDs, product IDs, quanity, order IDs, unit price are required fields and must be validated.
Region IDs and product IDs are checked with reference files.

A message is invalid if it doesn't contain the require fields.

### Kafka Messages

The messages describe sales information as they are happening 'real time'.

### Consumer Validation

The consumer uses regions.csv and products.csv to validate cost and add taxes to the total cost.

### Data Engineering and Enrichment

The consumer is referencing regions.csv to add taxes and a total cost to the table.

### Streaming Analytics

Totals were tracked, included sales tax.

### Experiments

Phase 4 change: increase producer message interval to 5seconds. Change was nominal.
Phase 5 change: increase producer max message to 75. Change was nominal.

### Results

The logs created from running the producer and consumer
included a summary of the scripts and whether they ran successfully.

My scripts were successfully ran and I received no errors.
